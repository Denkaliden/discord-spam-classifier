# discord-spam-classifier
university project: spam classifier for discord/ ml bot

Университетский проект по разработке модели для автоматической модерации сообщений в Discord.

* **Источник:** Выгрузка логов публичных серверов Discord (тематические каналы поиска игры, LOLRU Community).
* **Инструмент сбора:** [DiscordChatExporter](https://github.com/Tyrrrz/DiscordChatExporter) (формат CSV).

## Структура проекта
* `src/` — исходный код.
    * `prepare.py` — скрипт первичной обработки сырых логов.
* `data/` — папка для данных (игнорируется Git).
    * `raw/` — сырые выгрузки от DiscordChatExporter.
    * `processed/` — очищенные данные для разметки.
 
* Бизнес задача:
   *  Что улучшаем?: Меньше флуда, разгрузка модераторов, каналы активнее используются по назначению. 	Флудом считаем любые нерелевантные сообщения не по тематике канала
   *  Что сделают с прогнозом?: Удаляем сообщение, выносим пользователю предупреждение
*ML-задача: 
   *  для чего и когда прогноз: Для сообщения, после его появления.
   *  Таргет: Является сообщение флудом или нет(1/0)
   *  Тип задачи: Бинарная классификация
* Данные и признаки: 
   *  Откуда данные, сколько их: Данные из открытых серверов дискорда, парсинг, данных очень много.
   *  Признаки на момент прогноза: сообщение, имя пользователя, дата, история пользователя.
*Метрика и проверка: 
   *  Метрика: precission recall, PR AUC
   *  Бейзлайн без ML: Проверка по ключевым словам, повтору символов
   *  Как делим Данные: Делим train и test по разным серверам или играм. 
* Результат: 
   *  В каком виде результат: собираем график флуда от общего числа сообщений. Можно собрать список удаленных.
   *  Как поймем, что работает: Проверяем и сравниваем статистику ухода пользователей и частоты использования каналов с использованием и без использования бота.
